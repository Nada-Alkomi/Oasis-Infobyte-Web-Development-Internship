## Internship Tasks

###  Task 1 – Landing Page

**Objective:** Design and develop a professional and responsive landing page.

**Features:**
- Modern and clean user interface.
- Responsive layout for different screen sizes.
- Organized sections and navigation.
- Consistent colors and typography.
- Interactive buttons and links.

**Technologies:** HTML5, CSS3.

---

###  Task 2 – Personal Portfolio

**Objective:** Create a personal portfolio website to showcase my professional profile.

**Features:**
- Hero section with personal introduction.
- About Me section.
- Technical Skills section.
- Projects showcase.
- Contact information and social media links.
- Responsive design.
- Smooth scrolling navigation.

**Technologies:** HTML5, CSS3, JavaScript (Optional).

---

###  Task 3 – Temperature Converter

**Objective:** Build an interactive temperature conversion tool.

**Features:**
- Input field for temperature values.
- Celsius, Fahrenheit, and Kelvin unit selection.
- Convert temperatures between different units.
- Display all conversion results simultaneously.
- Input validation and error handling.
- Absolute zero validation.
- Responsive and user-friendly interface.

**Technologies:** HTML5, CSS3, Vanilla JavaScript.
